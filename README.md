# 🍽️ TastyTreats – Restaurant Showcase Website
TastyTreats is a static, responsive front-end restaurant website built using HTML and CSS. This project was developed to practice and improve my UI design skills using custom styles and layouts without relying on any frameworks.

The site features a clean landing section, menu highlights, promotional banners, and a stylish contact/subscription area — all crafted with modern design principles using pure CSS.
