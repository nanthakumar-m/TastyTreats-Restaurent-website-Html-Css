# 🍽️ TastyTreats – Restaurant Showcase Website
TastyTreats is a static, front-end restaurant website built using HTML and CSS. This project was developed to practice and improve my UI design skills using custom styles and layouts without relying on any frameworks.

The site features a clean landing section, menu highlights, promotional banners, and a stylish contact/subscription area — all crafted with modern design principles using pure CSS.

🔗👉 click here to see the live demo-->https://nanthakumar-m.github.io/TastyTreats-Restaurent-website-Html-Css/

🚫 Note: This website is not responsive and is best viewed on desktop screens.

## ⚙️ Technologies Used

- HTML5
- CSS3

## 🎯 Learning Objectives / Concepts Practiced

This project was developed to strengthen my front-end design skills by focusing on:

✅ CSS layout techniques (Flexbox, absolute positioning)

✅ Building structured page sections (banner, menu, contact, etc.)

✅ UI styling (colors, fonts, spacing, hover effects)

✅ Smooth scroll navigation and visual flow

✅ Typography and aesthetic improvement using custom fonts
